**TOPICOS 1 - 4** 




Os quatro primeiros tópicos apresentam os conceitos fundamentais para quem está iniciando no uso do Git e do GitHub. Inicialmente, é importante compreender o que é o Git, uma ferramenta de controle de versão utilizada para registrar alterações em arquivos e projetos ao longo do tempo. Sua principal função é organizar o desenvolvimento e permitir que diferentes pessoas trabalhem em um mesmo projeto sem perder versões anteriores. Diferente de apenas salvar arquivos normalmente, o Git registra cada alteração realizada, facilitando o acompanhamento do histórico e a recuperação de versões anteriores.

Em seguida, é apresentado o GitHub, uma plataforma online utilizada para armazenar, compartilhar e gerenciar projetos que utilizam Git. Além de guardar códigos e arquivos na nuvem, o GitHub permite colaboração entre desenvolvedores e também funciona como um portfólio profissional, especialmente importante para estudantes e iniciantes da área de tecnologia que desejam mostrar seus projetos e evolução.

Outro ponto importante é a criação e configuração da conta no GitHub. O perfil deve ser tratado como uma apresentação profissional, utilizando um nome de usuário adequado, uma foto apropriada, descrição organizada e informações básicas bem configuradas. Um perfil organizado transmite mais profissionalismo e facilita a identificação das habilidades do usuário.

Por fim, a personalização da página inicial do perfil permite criar uma apresentação mais completa. Isso pode ser feito por meio de um repositório especial e do arquivo README.md, onde o aluno pode inserir informações pessoais, interesses, conhecimentos e projetos desenvolvidos, tornando seu perfil mais organizado e atrativo.
